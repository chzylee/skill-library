## Affected Pages/Routes
- `~/.claude/study/index.html` — the served library view. Topic list, facets, tags, progress.
- `~/.claude/study/index.html#<topic>` — topic reading view. Chapters, items, disclosure, sources.

## Key Interactions to Verify
- Expand a chapter, then an item, then follow the source link out. Confirm click depth is 1 / 2 / 3.
- Keyboard only: tab to a chapter, Enter to expand, tab into items, expand, reach the source link.
- Screen reader: heading navigation reaches every chapter title (h2) and item title (h3).
- Search across topics, land on a hit, confirm it opens expanded inside its chapter.
- Toggle a facet, confirm the topic list narrows and the count updates.
- Add and remove a manual tag; rebuild; confirm it survives (slice 3).
- Mark a chapter read; rebuild; confirm progress survives the rebuild (slice 3).

## Edge Cases
- Empty store: builder writes `index.html` with the first-run empty state, exit 0. It must NOT `sys.exit(1)`.
- Legacy topic (no chapters): renders flat under a banner, offers restructure.
- Topic failing its gates: renders flat under a banner; every OTHER topic still builds.
- Dead source (404), unopened source, bot-walled source: three visually distinct states, readable without hover.
- Chapter with 1 member; topic with 15+ rows and fewer than 3 chapters (must fail its own gate).
- Unreadable markdown file in the store: named in the output, not silently dropped.
- Two viewers running at once: second picks a free port rather than crashing.
- Tab closed: server exits within ~12s. Kill the browser process: server still exits.
- Re-run a topic that has progress recorded: marks attach to the right rows, or are explicitly reset (slice 3).

## Critical Paths
- `/study <topic>` end to end on a real topic, then `/study-read`, then read a chapter and reach a source.
- Slice 1 validation: structure stage over 3-5 existing runs, independent checker scores each chapter
  principle / restatement / surface, and each failure is attributed to method or to input.
  Pass condition: ≥70% principle overall, no topic below 50%, method failures ≤ input failures.
- Rebuild with all 238 legacy rows present: every one still renders, `kind: unclassified`, no chapters.
